# AI-Powered Student Assistant

An AI-powered desktop learning assistant that helps students learn faster:
intelligent question answering, concept explanations, automated note
generation, MCQ solving, and personalised learning progress tracking.

## Features

- Ask questions and get clear, structured explanations
- Generate notes from study material
- Practise with MCQs and track progress over time
- Designed for students who want study help in one place

## Tech

Python, OpenAI API, desktop UI. See the source in this repository for
the exact setup for your environment.

## Run

```bash
pip install -r requirements.txt
python main.py
```

Replace `main.py` with the entry point in this repo if it differs, and
set your OpenAI API key in your environment before running.
