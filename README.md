# AI-Powered Student Assistant

An AI-powered desktop learning assistant intended to help students learn faster, with intelligent question answering, concept explanations, automated note generation, MCQ solving, and personalised learning progress tracking.

## Intended features

These are the capabilities described in the project description:

- Intelligent question answering
- Concept explanations
- Automated note generation
- MCQ solving
- Personalised learning progress tracking

## Tech

Planned stack per the project description: a desktop application that uses the OpenAI API.
