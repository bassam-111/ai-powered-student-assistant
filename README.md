An interactive student assistant powered by **Claude claude-opus-4-5** — the smartest model available for complex academic reasoning.

**Claude claude-opus-4-5 is the smartest choice** for a student assistant because it excels at multi-step reasoning, nuanced explanations, and handling the full breadth of academic subjects.

## Features

- Multi-turn conversation with memory of previous questions
- Covers all academic subjects (math, science, history, literature, etc.)
- Step-by-step problem solving
- Encourages critical thinking

## Setup

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=your_api_key_here
python assistant.py
```

## Usage

Run the assistant and ask any academic question:

```
You: Explain the Pythagorean theorem
Assistant: The Pythagorean theorem states that in a right triangle...

You: Can you give me a harder example?
Assistant: Sure! Let's work through a problem with a 5-12-13 triangle...
```
